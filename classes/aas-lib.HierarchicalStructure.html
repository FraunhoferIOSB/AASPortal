    toggleSelection

    • toggleSelection(node?: TreeNode<aas.Entity, NodeOptions>): void

      Toggles selection state for a given tree node or for the entire tree.

      Behavior:

      • If node is provided:
        • Toggles the selected flag of the provided node.
        • If this.selectionMode() returns 'single', any other node that is currently selected will be unselected (ensures only one node remains selected).
      • If node is omitted:
        • If everySelected is true, clears selection on all nodes.
        • Otherwise, selects all nodes that are not currently selected.

      Parameters

      • Optionalnode: TreeNode<aas.Entity, NodeOptions>

        Optional tree node to toggle. When omitted, toggles selection state for the whole tree.

      Returns void
