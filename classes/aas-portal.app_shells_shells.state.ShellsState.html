    getPreviousPage

    • getPreviousPage(): void

      Retrieves the previous page of documents based on current pagination settings. This method makes an API call to fetch documents using the current 'previous' cursor, limit, filter text, and language settings. If there are no documents currently loaded, the method returns early without making any requests.

      The retrieved documents are then processed through setPageAndLoadContents and the results are subscribed to update the current state.

      Returns void
