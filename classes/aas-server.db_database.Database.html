    dirUpdated

    • dirUpdated(backup: string, dir: string): void

      Records an updated directory by storing a tuple containing the backup and directory paths in the updatedDirs array of the memento object.

      This method is typically used during database operations that modify directory contents, allowing the system to keep track of which directories were updated, as well as their corresponding backup paths. This facilitates rollback or commit operations.

      Parameters

      • backup: string

        The path to the backup directory.

      • dir: string

        The path to the updated directory.

      Returns void
